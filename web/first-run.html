    5. Check audio

    Start the radio only with an antenna or dummy load attached and the correct frequencies programmed. This enables the RF audio path. No automatic test tone is sent.

    Disconnect network links before changing levels. Applying levels restarts the radio service. Check clear receive and transmit audio with another radio; these starting levels are not a calibration.
