# Existing station updates

The fresh installer and bootstrap must not be run over a configured station. Updates require an inspected baseline, backups, explicit service-impact review, hash verification and preservation of configuration, authentication, profiles and radio programming state. Do not copy old deployment manifests to a different installation.

The October 30 repair was applied as reviewed patches to the existing station; this source package incorporates those corrections. It does not automatically deploy itself or program a radio.
